# 霧港十三夜：第十三聲

Inky 繁中版的預設互動教學。你在渡鴉舊書店遇見一位沒有影子的來客，帶著藍皮書前往鐘塔，與記錄官沈月決定霧港的黎明。

## 開始操作

從程式的「範例 → 開啟範例：霧港十三夜（角色與分支教學）」開啟。手動開檔時請選本資料夾的「主程式.ink」，並保留其他四個 .ink 檔在同一資料夾。

右側預覽點選選項，依序決定姓名、背景、5 點屬性與 4 點技能；分配完才會出現繼續選項。屬性範圍 1～4、技能範圍 0～3，可以退點、重設與返回調整。接著調查書店、取得藍皮書，再前往鐘塔。

每次調查只能選一條路，不能重複取得信任或線索。「查看角色」可反覆使用。結局後使用 Inky 的重新開始按鈕體驗其他路線。

## 姓名、記憶與存檔

- 姓名提供三種選擇。要用自己的名字，將「主程式.ink」開頭的 `VAR hero_name = "林晝"` 改成自己的字串，重新開始後選「使用目前的名字」。
- 右側預覽沒有自由文字輸入框或數字輸入表單。其他遊戲的 `#TEXTINPUT`、`#NUMBERPOOL` 是由遊戲宿主解讀的標籤，單純寫進 Ink 不會在 Inky 產生輸入元件。
- 名字、屬性、技能、物品、信任、線索與調查結果由 Ink 記住，後續敘事與選項會讀取它們。檢定是固定加總，不使用隨機骰數。
- 保存 .ink 是保存劇本原始碼，並非保存玩家進度。此範例未實作關閉後接續的存檔系統；重新開始會重設。Ink runtime 能序列化狀態，但存放、載入與存檔介面需要宿主另外實作。
- 選單會複製一份可編輯範例至 Inky 的使用者資料目錄，重開不覆蓋你的修改。需要乾淨副本時，請複製測試包「範例」資料夾中的整個「霧港十三夜」。

## 對照學習

| 檔案 | 用法 |
|---|---|
| 主程式.ink | VAR 字串／數字／布林、LIST 定義、INCLUDE 多檔案入口、說明選單 |
| 角色建立.ink | 條件選項、變數指定、數值上下限、點數守恆、退點與重設 |
| 雨夜來客.ink | `*`／`**`／`***` 三層一次性選項、`+` 可重複選項、訪問次數、條件敘事、LIST 物品 |
| 鐘塔議會.ink | 技能檢定、多入口匯流、失敗代價、條件結局、姓名變更 |
| 系統工具.ink | function 回傳加總；`-> character_sheet ->` 與 `->->` 共用狀態段落並返回 |

調查＝洞察＋觀察；儀式＝洞察＋儀式；交涉＝共感＋交涉。書店檢定門檻為調查 4／交涉 4／儀式 5，鐘塔前交涉門檻 5，抬門需要體魄 3。

## 四條可重現路線（含結局提示）

1. **第十三夜歸來**：背景選港口跑腿人；屬性洞察加 3、共感加 2；技能儀式加 3、觀察加 1。和來客交談 → 追問書的來歷 → 答應保護；閱讀藍皮書；前往鐘塔 → 向沈月坦白 → 用銅鑰匙開門 → 一起改寫契約。
2. **留下證詞的人**：背景選書店繼承人；屬性洞察加 3、共感加 2；技能觀察加 3、儀式加 1。和來客交談 → 問影子；調查書桌 → 檢查信紙；前往鐘塔 → 坦白 → 嘗試抬門（此角色失敗但仍能前進）→ 公開議會記錄。
3. **被海帶走的名字**：任意合法角色，和來客交談取得書後前往鐘塔；抵達沉潮廳時選「用自己的名字」。結尾會記住原名，同時將顯示姓名改為無名旅人。
4. **留給明天的問題**：任意合法角色取得書並抵達沉潮廳，選「先帶著書撤離」。

改寫契約需聽見回聲、信任至少 2、儀式分數至少 5、鐘聲壓力不超過 2。公開記錄需至少 2 條線索、調查分數至少 5。另兩個結局永遠可選。
