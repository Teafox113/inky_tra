# 操作示範

本資料夾的教學版本依根目錄 MIT License 提供，不包含第三方商業遊戲劇本或素材。

- `霧港十三夜/主程式.ink`：預設完整教學；角色建立、點數分配、三層分支、物品、檢定與四種結局。依使用者指示改編其 Novel Studio 範例設定，新增 Ink 敘事與流程，來源及路線見該資料夾 README。

- `雨天書店/主程式.ink`：繁體中文、中文路徑、選項、變數、條件與跳轉。
- `translation-practice/practice.ink`：英文翻譯練習。
- `translation-practice/glossary.csv`：練習用詞彙表。

翻譯與儲存測試前，複製至工作區 `.local/`，避免把練習輸出混入發布檔案。
