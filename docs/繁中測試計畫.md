## 互動驗收（尚待逐項完成）

| 項目 | 操作 | 預期 |
|---|---|---|
| 初次啟動 | npm start | 新版獨立設定目錄，不載入舊 Key／最近遊戲 |
| 介面語言 | 繁中→英文→繁中，重啟 | 選單、設定與工具列切換，偏好保存 |
| 中文輸入 | 注音／倉頡／拼音輸入，退格與復原 | 不重複文字、不吃字、不誤觸快捷鍵 |
| 中文路徑 | 複製示範到 .local/測試 空白路徑/ | 能開啟、另存、重新開啟與編譯 |
| 劇情預覽 | 喝兩杯茶、看書、離開 | 變數與分支正常，中文標點正確 |
| 搜尋取代 | 搜尋「書店」，逐筆／全部取代，再復原 | 命中與計數正確，復原完整 |
| About | 原版 About 及擴充說明頁 | 名稱、1.8.0-dev.2、日期、FloofyFox 與 inkle 資訊一致 |
| LUA/TXT | 原創空白 Lua/TXT 檔開啟、編輯、另存 | 不送入 Ink 編譯器；逐項確認現有實作 |
| 翻譯 API | 用原創英文示範測試單檔與選取 | 詞彙表生效，語法可編譯，費用記錄合理 |
| API 失敗 | 無 Key、錯誤 Key、取消／斷線 | 清楚回饋，不覆蓋未儲存內容 |
| AI 助理 | 附加原創示範、切換角色、存記憶 | 正確上下文、無靜默改檔、資料目錄隔離 |
| Portable | 解壓至中文含空白路徑，再啟動 | EXE 屬性、About、範例、編譯器均正常 |

API 驗證需使用者設定可用服務；目前沒有代入或複製任何 API Key。每項完成後在任務日誌記錄實際結果，未測不得寫成通過。
